# F40 · Evidence Recommendation Gate

Version: `evidence-recommendation-gate-v0.1`.

F40 is the first phase allowed to emit a candidate improvement recommendation,
but only from a human-reviewed experiment result that F39 has marked eligible.

Associations from F38 are never sufficient by themselves.

A candidate recommendation:

- references one experiment/hypothesis;
- recommends only the tested variant;
- records the observed delta;
- still requires human approval.

F40 does not edit the project, update director policy, auto-apply a change or
publish content. That boundary is reserved for later phases after the learning
contract has been audited with real data.
