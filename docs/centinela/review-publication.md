# R8 Review Studio + Publication Package

R8 closes the product path from `VIDEO_BASE_READY` to an explicitly human-approved, manual-publication package.

## Flow

`VIDEO_BASE_READY -> REVIEW_PREP -> READY_FOR_HUMAN_REVIEW -> FINAL_APPROVED -> PUBLICATION_PACKAGE -> PUBLICATION_PACKAGE_READY`

Review Studio consumes the R7 `FinalScript`, media selection/resolution, mastered audio, clean social/master video bases, review preview and subtitle sidecar. It does not invoke a new LLM, does not discover network media, does not call WanGP and does not authorize publication.

## Human review contract

Approval requires all seven explicit checks:

- science verified;
- visual match verified;
- audio quality verified;
- subtitle text verified;
- media rights verified;
- thumbnail verified;
- publication copy verified.

The hard rights gate must also pass. Owned media or verified-license media are accepted; restricted, unverified, incomplete-license and AI-recreation selections are blocked in R8 v0.1. `approved=True` is content approval only. `publication_authorized` and `auto_publication` remain `false`.

## Finalization

R8 keeps the R7 video image stream intact and muxes the already-mastered voice with FFmpeg using `-c:v copy` plus AAC audio at 48 kHz. The 2160x3840 master is finalized from the R7 master artifact, never from the 1080x1920 social artifact.

## Publication package

The ZIP root is `publication/` and contains:

- `master_2160x3840.mp4`
- `social_1080x1920.mp4`
- `thumbnail.jpg`
- `caption-instagram.txt`
- `caption-tiktok.txt`
- `title-youtube.txt`
- `description-youtube.txt`
- `hashtags.txt`
- `metadata.json`
- `provenance.json`
- `licenses.json`
- `review-checklist.json`
- `subtitles-es.srt`
- `publication-manifest.json`

The persisted `publication_package_manifest` artifact is authoritative for the final ZIP SHA256. The manifest inside the ZIP deliberately leaves its own ZIP hash null because a ZIP cannot contain its own final hash without recursion.

## Guardrails

- no automatic publication;
- no publication authorization generated by R8;
- no WanGP;
- no model download;
- no LLM rerun for publication copy;
- no network requirement;
- human review remains mandatory;
- architecture freeze remains outside R8.
