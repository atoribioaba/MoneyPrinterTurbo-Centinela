# F39 · Experiment Evidence Ledger

Version: `experiment-evidence-ledger-v0.1`.

F39 records explicitly supplied experiment outcomes against hypotheses already
released by F35.

An experiment result is eligible for later recommendation review only when the
operator confirms:

- randomized assignment;
- the same measurement window;
- human review.

V0.1 records observed absolute/relative deltas but does not calculate p-values,
claim statistical significance or automatically claim causality. It does not
run experiments or write a database.
