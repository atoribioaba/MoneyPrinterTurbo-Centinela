# F19 · Color Science

Version: `color-science-v0.1`.

F19 translates the explicit cinematic mood from F8 into a conservative,
deterministic grade intent. It does not inspect pixels, apply LUTs or render.

Principles:
- preserve natural astronomy colour;
- avoid clipping and oversaturation;
- restrained contrast;
- no fake HDR look;
- placeholders remain no-op.

Measured correction belongs to later render/quality stages; F19 only defines the
creative and technical target.
