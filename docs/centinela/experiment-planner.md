# F35 · Experiment Planner

Version: `experiment-planner-v0.1`.

F35 is the first bridge from analytics to future improvement, but it remains
strictly evidence-gated.

Rules:

- insufficient analytics suppress all candidate experiments;
- available evidence can release only explicitly supplied hypotheses;
- each experiment changes one variable;
- no causal claim is made before an experiment;
- F35 does not edit the project, run the experiment or publish content.

This is intentional: the future Self-Improving Video Director must learn from
controlled evidence rather than automatically chasing noisy platform metrics.
