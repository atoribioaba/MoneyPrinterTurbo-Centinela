# F24 · Audio Mastering

Version: `audio-mastering-v0.1`.

F24 defines the audio-mastering target without touching audio.

The project target is:

- integrated loudness: `-16 LUFS`;
- loudness range target: `7 LU`;
- maximum true peak: `-1 dBTP`;
- method: FFmpeg `loudnorm`, two-pass when a file mix actually exists.

These values are an internal **project target**, not a claim that Instagram,
TikTok or YouTube enforce one universal loudness value.

V0.1 is blocked until voice audio exists and F22 sound assets have been selected
with verified rights. No audio render, modification or publication occurs.
